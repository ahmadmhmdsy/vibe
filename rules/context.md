# Context rules

- The document map in AGENTS.md is the index — a doc outside it does not
  exist for the next agent.
- When evidence conflicts, render UNKNOWN and resolve from source
  artifacts — never let an older value silently win.
- Stable documents (AGENTS.md, SOUL.md, rules/) change only with an
  auditable diff and an explicit adoption decision.
- Live truth lives in CURRENT_STATE.md and TASKS.md; narrative evidence
  in HANDOFF.md; durable knowledge in MEMORY.md.
- A new durable knowledge kind must land in the document map.
